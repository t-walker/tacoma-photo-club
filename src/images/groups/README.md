# Event group shots

One photo per event, named after that event's `id` in `src/data/events.json` —
`bowling-meetup.jpg` belongs to the event with `"id": "bowling-meetup"`. The
file name *is* the link, so there is nothing to register in JSON.

It is laid over the foot of the event's flier on the Events page. Events
without a group shot just show their flier, so a missing file is fine.

Landscape works best, around 1600px wide.
